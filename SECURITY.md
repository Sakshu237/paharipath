# Security Policy

PahariPath is a continuously-deployed web app (paharipath.in), not a
versioned library — there's no separate branches or releases to track.
The version currently live on paharipath.in is always the one receiving
security fixes; older commits are not maintained separately.

## Reporting a Vulnerability

If you've found a security issue in PahariPath (data exposure, an auth
bypass, XSS, or anything similar), please email **hello@paharipath.in**
with:
- A description of the issue and its potential impact
- Steps to reproduce it, if possible
- Any relevant URLs, requests, or screenshots

Please don't open a public GitHub issue for security reports — email
first so it can be fixed before details are public.

**What to expect:**
- Acknowledgement within 3–5 days
- A fix timeline once the issue is confirmed, based on severity
- Credit in the fix notes if you'd like it, once resolved

There is currently no bug bounty program — this is a solo-founder
project — but genuine reports are taken seriously and fixed promptly.
